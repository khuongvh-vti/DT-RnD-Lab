# Kho tài liệu của Phòng R&D (anh bỏ file PDF/MD/TXT vào đúng thư mục)

Các agent chỉ trả lời dựa trên những gì có trong kho này. Kho càng đầy đủ, báo cáo càng sâu.
Tiêu chuẩn IEC/IEEE và CIGRE TB là tài liệu có bản quyền: dùng bản công ty đã mua, **không** đưa lên GitHub
(thư mục library/ đã được loại khỏi git trong `.gitignore`).

| Thư mục | Nên có (ưu tiên từ trên xuống) |
| --- | --- |
| 01_standards | IEC 60076-7 (loading guide), IEC 60599 (DGA), IEC 60270 (PD), IEEE C57.91, IEEE C57.104, IEC 61850-7-4 (logical nodes), IEC 62443-3-3, ISO/IEC 30173 |
| 02_cigre_ieee | CIGRE TB 995 (Transformer DT, 2026), TB 761 (condition assessment), TB 227, TB 298, TB 630, các paper CIGRE Session 2024–2026 về DT |

| 04_vietnam | Luật Điện lực 2024, NQ 57, QĐ 538, quy định kỹ thuật/hồ sơ mời thầu giám sát online của EVN, NPT, các TCT |
| 05_papers | Paper IEEE/Elsevier về transformer DT, hybrid physics-ML, health index |
