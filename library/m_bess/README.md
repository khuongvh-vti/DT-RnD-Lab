# Thư mục tài liệu module BESS & Tích hợp năng lượng tái tạo

Đặt PDF/MD/TXT của module **BESS & Tích hợp năng lượng tái tạo** vào đây (hoặc kéo thả trong tab 📚 Kho tài liệu) rồi bấm “Nạp vào kho”.

Mục tiêu: Nắm công nghệ, tiêu chuẩn an toàn và mô hình kinh doanh của hệ thống lưu trữ pin (BESS) và đấu nối NLTT để tìm phần việc VTI làm được: giám sát, EMS, cảnh báo cháy, tích hợp SCADA.
