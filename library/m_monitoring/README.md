# Thư mục tài liệu module Online Monitoring & Chẩn đoán

Đặt PDF/MD/TXT của module **Online Monitoring & Chẩn đoán** vào đây (hoặc kéo thả trong tab 📚 Kho tài liệu) rồi bấm “Nạp vào kho”.

Mục tiêu: Làm chủ công nghệ giám sát tình trạng online (PD, DGA, nhiệt độ, bushing, DTS cáp) – nguyên lý cảm biến, thuật toán chẩn đoán, tiêu chuẩn nghiệm thu – để nâng cấp bộ giải pháp chào hàng của VTI.
